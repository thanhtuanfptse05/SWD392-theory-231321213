## 🌟 Tính Năng Nổi Bật

- **Toàn diện 100% kiến thức**: Bao phủ 24 chương học lý thuyết từ Ch01 đến Ch24.
- **23 Mẫu thiết kế GoF (Gang of Four)**: Đầy đủ Intent, cấu trúc UML, Participants, Use Cases và mã nguồn Java minh họa chuẩn với cú pháp màu VS Code.
- **5 Nghiên cứu thực chiến (Case Studies)**: Hệ thống Banking ATM, Sàn thương mại điện tử SOA, Hệ thống giám sát cấp cứu CBD, Xe tự hành thời gian thực AGV, và Đồ án FreshFood Online Shopping (FOS).
- **Chuyên đề GenAI hiện đại**: Ứng dụng Prompt Engineering, Text-to-UML với PlantUML và hỗ trợ thiết kế kiến trúc với GitHub Copilot.
- **Công cụ tương tác & Trắc nghiệm**:
  - Tra cứu & lọc 23 mẫu GoF theo nhóm Creational, Structural, Behavioral.
  - Ma trận so sánh định lượng 5 phong cách kiến trúc (Monolith, 3-Tier, SOA, Microservices, Real-Time).
  - Bộ tính toán độ sẵn sàng (Availability) và cận trên lập lịch thời gian thực Rate Monotonic Analysis (RMA).
  - Hệ thống 25 câu hỏi trắc nghiệm đa chương có chấm điểm tức thì và giải thích chi tiết.
- **Kiến trúc Zero-Build Monolithic SPA**: Tích hợp toàn bộ HTML, CSS và JS trong tệp duy nhất `index.html`. Hỗ trợ chế độ Sáng / Tối (Light / Dark mode), phím tắt tìm kiếm `Ctrl + K`.
